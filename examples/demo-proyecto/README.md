# Proyecto de demostración

Cálculo de promedios y búsqueda de usuarios.

Este archivo simula un proyecto heredado con defectos. Úsalo para probar al
agente en modo `consulta` sin riesgo para nada real.

```bash
python -m agent.cli ask --profile consulta --workspace examples/demo-proyecto \
  "Revisa app.js, lista los defectos y propone el arreglo"
```
